# lor_project

## Project Description

This project is a Flutter Web starter application developed for IT 110 – Web Systems and Technologies, Laboratory Activity No. 8. It establishes the initial user interface, source-code organization, and navigation structure for our semester project.

## Technology Stack

- **Dart and Flutter Web** – Used to develop the client-side user interface and navigation.
- **REST API** – Planned for future server-side processing and business logic.
- **PostgreSQL** – Planned for future data storage and database management.
- **Git and GitHub** – Used for version control and source-code collaboration.

## Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Visual Studio Code
- Google Chrome
- Git

### Installation

1. Clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open the terminal in the project directory.
4. Install the project dependencies:

   `flutter pub get`

5. Run the Flutter Web application:

   `flutter run -d chrome`
